OddSockets Rust SDK - live two-client regression proof
=======================================================

Captured by running `cargo run` with a real OddSockets API key against the
live platform (Manager -> Worker discovery, genuine Socket.IO WebSocket per
client). Two SEPARATE connections (alice, bob); no mocks, no local echo.

Scenario 1  core pub/sub: bob publishes, alice receives on her broadcast
            receiver across an independent connection.
Scenario 2  enhanced events: bob fires enhanced.start_typing and
            enhanced.add_reaction; alice receives user_typing and
            reaction_added on her public on() surface, over the wire.

API key redacted below.
